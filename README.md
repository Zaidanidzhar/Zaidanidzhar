## Project Unggulan

### 🔹 [Customer Segmentation: RFM & K-Means](https://github.com/Zaidanidzhar/Segmentation-Cust-apk)
Aplikasi web untuk segmentasi pelanggan dari data transaksi toko online. Laravel menangani antarmuka dan data, sedangkan proses machine learning berjalan di layanan FastAPI terpisah. Hasilnya berupa 4 segmen pelanggan (Champions, Loyal, At Risk, Hibernating) yang ditampilkan di dashboard.
**Stack:** Laravel 12, FastAPI, scikit-learn, pandas, SQLite/MySQL, Tailwind CSS

### 🔹 [POS Sederhana (Kasir Mini)](https://github.com/Zaidanidzhar/java-project)
Aplikasi kasir berbasis Java dengan login multi-role (admin dan kasir), manajemen produk, transaksi, cetak struk otomatis, dan laporan penjualan.
**Stack:** Java, NetBeans, MySQL
